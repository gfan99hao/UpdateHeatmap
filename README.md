# UpdateHeatmap — Typecho 更新热力图插件

AI附体的情况下搞出来的适用于 Typecho / TypeRenew 可以在模板任意位置显示类似 GitHub 的文章更新热力图。

演示：[别催别催](https://biecui.com)

## 数据说明

- **新建**：按文章 `created` 时间按日统计已发布文章。
- **修改**：按文章 `modified` 时间统计。⚠️ Typecho 数据库只保存**最后一次**修改时间，无法还原历史修改记录，因此“修改次数”实际是“当日发生修改的文章数”（modified 晚于 created 至少 1 小时才计入）。
- 单日活动量 = 新建数 + 修改数。

## 安装

1. 将 `UpdateHeatmap` 文件夹放入 `/usr/plugins/`。
2. 后台「控制台 → 插件」启用。
3. 点击「设置」配置参数。

## 设置项

| 设置 | 说明 |
|---|---|
| 显示时间范围（天） | 向今天追溯的天数，如 180 / 365 / 730 |
| 颜色风格 | GitHub 绿 / 蓝 / 紫 / 橙 / 粉 / 黑白 |
| 色阶数量 | 颜色分几档（含空档），建议 3–5 |
| 每档阈值 | 单日活动量达到多少换一档颜色；0 = 按最大值自动均分 |
| 数据缓存时长 | 聚合查询结果缓存秒数（默认 3600，0 禁用）；建议保留——文章发布、修改、状态变更或删除时会自动清除缓存，前台数据即时更新 |

## 显示位置

本插件**不会自动注入**任何页面位置，完全由手动插入控制。在主题模板（如 `footer.php`、`sidebar.php`、`post.php`）需要显示的地方加入：

```php
<?php \TypechoPlugin\UpdateHeatmap\Plugin::output(); ?>
```

可多处调用，也可只在文章页/首页显示——完全跟随模板逻辑。

## 自适应说明

热力图宽度 100% 跟随父容器，格子用 `flex: 1` + `aspect-ratio: 1` 等比缩放：宽容器格子变大，窄容器（侧边栏）格子自动缩小，极窄（<约 320px）时横向滚动兜底，不会撑破布局。字号为固定 12px，不随格子缩放。

## 自动刷新

插件挂载了文章编辑钩子（`Widget\Contents\Post\Edit` 的 `finishPublish` / `finishSave` / `finishMark` / `finishDelete`）：**发布、修改、隐藏/显示或删除文章后，热力图缓存会立即清除**，前台下一次渲染即为最新数据，无需手动清理缓存或等待缓存过期。

## 环境要求

- PHP 7.4+（PHP 8.x 均可用）
- Typecho 1.2.1+ / 1.3.0，及其衍生分支 TypeRenew（1.6.x 已验证兼容其 `TypechoPlugin\` 插件命名空间规范）

> 启用白屏排查：若插件启用失败，多半是插件入口类命名不符合宿主约定。本插件入口类为 `TypechoPlugin\UpdateHeatmap\Plugin`，文件夹名必须为 `UpdateHeatmap`。
